## 怎么用这份清单

- **规模**：S ≈ 半天内，M ≈ 1～2 天，L ≈ 3 天以上（含调试与验证）。
- **依赖**：该任务开始前必须先完成的任务编号。`—` 表示无前置依赖。
- **验收标准**：做完怎么算通过。凡是涉及排盘的，都必须过 `npm test`。
- 已完成的打 ✅，进行中的打 🚧。
